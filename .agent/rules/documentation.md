# Documentation Rules

- Root `AGENTS.md` keeps only mandatory principles.
- Project workflows, checklists, and non-core conventions belong in `.agent/rules/`.
- Reusable operation steps may be added under `.agent/skills/` when they become stable and repeatable.
- Module-specific intent belongs in the module README or module-level `AGENTS.md`.
- Use Mermaid for UML, sequence diagrams, flowcharts, or state diagrams.
- Prefer concise tables for comparisons and decision records.
