# v3.0 — 反指纹 · 代理隔离 · Persistent Context

**日期**: 2026-04-10  
**分支**: `main`  

## 概要

实现容器化浏览器的 **反指纹检测** 和 **代理隔离** 能力。每个浏览器实例拥有唯一且持久的身份指纹（Canvas/WebGL/Audio 噪声、硬件参数伪装），通过 GeoIP 自动匹配代理所在地的时区/语言/地理位置，并通过本地代理 Relay 解决 Playwright 与需认证代理的兼容性问题。

## 为什么需要本地代理 Relay

| 行为 | curl | Chromium (Playwright) |
|---|---|---|
| 首次 CONNECT | 直接带 `Proxy-Authorization` | **不带认证**（先裸连） |
| 收到 407 后 | — | 重试时才带认证 |
| 代理服务器反应 | 正常 | 标记为可疑，后续请求超时 |

**解决方案**: 在本地 `127.0.0.1:131xx` 启动一个 TCP Relay，预注入 `Proxy-Authorization` 头。Chrome 连接本地代理（无需认证），Relay 转发到上游代理（已带认证），彻底绕过 407 重试问题。

## 变更明细

### 新增：指纹系统 (`fingerprint.py`)
- `Fingerprint` dataclass: user_agent, screen, canvas_noise, webgl_noise, audio_noise, fonts, hardware_concurrency, device_memory, locale, timezone, geolocation 等
- 首次创建后持久化到 `/data/browsers/{id}/fingerprint.json`，重启后自动加载
- 每个实例指纹唯一，跨容器重启保持一致

### 新增：Stealth 注入 (`stealth.js`)
- `navigator.webdriver` 隐藏
- Canvas 2D: `toDataURL` / `toBlob` 注入像素级噪声
- WebGL: `getParameter` 伪装 vendor/renderer，`readPixels` 注入噪声
- AudioContext: `getChannelData` / `getFloatFrequencyData` 注入噪声
- Screen/硬件: 覆盖 `screen.width/height`、`navigator.hardwareConcurrency`、`navigator.deviceMemory`
- 端口扫描保护: 拦截 localhost fetch 请求（白名单 SFU 8088 端口）

### 新增：GeoIP 自动匹配 (`geoip_utils.py`)
- 解析代理 URL 中的 IP，通过 GeoLite2 数据库查询地理位置
- 自动设置 `locale`、`timezone`、`latitude`、`longitude`
- 优先使用用户手动覆盖值

### 新增：代理认证 Relay (`proxy_relay.py`)
- 异步 TCP 服务器，在 CONNECT 请求中预注入 `Proxy-Authorization: Basic ...`
- 同一上游代理复用同一 Relay 端口
- 端口从 13100 起步自增分配

### 重构：Browser Instance
- 从 `launch()` + `new_context()` 改为 `launch_persistent_context()`（与 g2api 一致）
- 自动清理残留的 Chrome profile 锁文件（`SingletonLock` 等）
- `headless=False` + `--headless=new` + `ignore_default_args` 避免冲突
- 去除 `--enable-automation`、`--disable-web-security` 等暴露自动化特征的 flag

### 重构：Tab Publisher
- SDP 交换从浏览器 `fetch()` 改为 Python 端 `httpx`，完全绕过代理
  - Step 1: 浏览器 `getDisplayMedia` + `createOffer` → 返回 SDP
  - Step 2: Python `httpx.post()` 直接请求 SFU → 获取 answer
  - Step 3: 浏览器 `setRemoteDescription(answer)` → 完成
- 新增后台重试循环: 初次失败后 3s 起步、最长 15s 间隔持续重试

### Dockerfile
- 移除硬编码 `CHROME_PATH`，默认使用 Playwright 内置 Chromium
- 新增 `python-geoip-geolite2` 依赖

### 配置 (`config.py`)
- 新增 `BROWSER_DATA_DIR`、`DEFAULT_LOCALE`、`DEFAULT_TIMEZONE`

## 导航超时优化

- `page.goto()` timeout: 15s → 60s（适配代理延迟）
- `wait_until`: `load` → `domcontentloaded`（不等全部资源加载）

## 架构

```
Chrome (headless)
  ├─ Proxy: 127.0.0.1:131xx (ProxyRelay, 无认证)
  │   └─ → upstream proxy (带 Proxy-Authorization)
  ├─ getDisplayMedia → SDP offer
  │   └─ Python httpx → SFU 127.0.0.1:8088 (绕过代理)
  └─ stealth.js 注入 (Canvas/WebGL/Audio 噪声)
```
