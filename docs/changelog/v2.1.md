# v2.1 — View Groups · 文件传输 · 管理后台增强

**日期**: 2026-04-09  
**分支**: `feat-viewport-admin`  

## 概要

在 v2.0 SFU 基础上，新增 **View Group**（多标签页分组视图）、**文件上传/下载**（通过 Playwright filechooser 拦截），以及管理后台增强（Dashboard + 动态视口调整 + admin viewer 面板）。

## 变更明细

### View Groups（多 Tab 分组展示）
- 访问 `/viewer/{browser_id}` 展示该浏览器下所有活跃 tab 的 grid 布局
- Tab 卡片支持点击放大/缩小切换
- 视口尺寸变化时自动触发 stream refresh（`TabPublisher.refresh_stream()`）

### 文件传输
- **下载**: 监听 Playwright `download` 事件，自动保存至 `/data/downloads/{tab_id}/`，并通知 viewer
- **上传**: 拦截 `page.on("filechooser")`，通过管理 API 上传文件后自动填入浏览器文件选择对话框
- API: `GET /api/files/{tab_id}/{filename}` 提供文件下载

### 输入法 (IME) 修复
- 通过 `compositionstart` / `compositionend` / `compositionupdate` 事件实现中文输入法支持
- 区分 `isComposing` 状态，避免在组合输入过程中发送错误按键

### 管理后台
- Admin Dashboard: 展示所有浏览器实例及其 tab 列表
- 动态视口调整: `POST /api/admin/browsers/{id}/tabs/{tab_id}/viewport`
- Admin Viewer: 内嵌 iframe 直接在 dashboard 中预览 tab 画面

## Docker Compose
- 无架构变更，沿用 v2.0 SFU + TabShare 双容器模式
