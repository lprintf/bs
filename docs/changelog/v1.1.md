# v1.1 — 全球化 IME 输入法与 Playwright 键鼠高级封装支持

**日期**: 2026-04-07  
**分支**: `webrtc`  

## 概要

大幅重构底层的输入和控制系统，移除不稳定的底层 CDP `dispatchKeyEvent` 代码，迁移至 Playwright 高级鼠标与键盘 API。同时创新性引入前端“IME 隐藏沙盒”机制，首次解决跨平台、跨语言的中文/日文等本土输入法（IME）实时同步问题。

## 变更明细

### 前端 (`viewer.html`)
- **新增** 隐藏的高级输入沙盒 (`<textarea id="ime-trap">`) 代替原先的视频焦点。
- **修复** 多语言 IME 下原生按键乱码、特殊符号（Process、Unidentified）上报后导致浏览器无响应的问题。
- **新增** `compositionstart` 前端拼凑锁和 `compositionend` 后截取，解决拼写期间发信被吞噬及合成词重复的问题。
- **改进** 退格键 (Backspace) 等系统功能键在跨系统情况下的正常行为上报。

### 后端 (`webrtc_bridge.py`)
- **重构** 将基于 CDP 发送的裸数据 JSON 从底层替换为 `Playwright` 框架提供的高级库（`self.page.mouse` 及 `self.page.keyboard`）。
- **新增** `insertText` WebSocket 动作，支持在复杂 IME 合成结束和全选粘贴行为后在远端通过 `insert_text` 进行智能键入，替代单个独立按键输入。
- **修复** `postMessage` YouTube 和其他跨域环境所产生的脏数据（脏警告）干扰后台控制台。
- **完善** 键、鼠双端执行崩溃前加入 `try-except` 并向控制台预警报错。
