# v1.0 — WebRTC 原生标签页共享

**日期**: 2026-04-03  
**分支**: `webrtc`  
**提交**: `a43e1ac` → `d1d01b1`（共 3 次提交）

## 概要

底层从 CDP 截屏重构为 Chrome 原生 WebRTC。Python 退化为纯信令服务器，视频编码/传输完全由 Chromium 内核完成。

## 变更

### `a43e1ac` — refactor: WebRTC native tab sharing

- **新增** `webrtc_bridge.py` — WebRTC 信令桥接，通过 `page.evaluate()` 在 Chrome 内执行 `getDisplayMedia` + `RTCPeerConnection`
- **删除** `cdp_bridge.py` — 不再使用 CDP 截屏
- **删除** 扩展目录和测试脚本
- **新增** Dockerfile（基于 Playwright 官方镜像）
- **重构** `viewer.html` — 从 img 播放器改为 WebRTC `<video>` 播放器
- **重构** `tab_manager.py` — 添加 `--headless=new` 等关键启动参数

### `d3d3528` — feat: CDP input dispatch + viewer auto-reconnect

- **新增** CDP Session 输入分发（鼠标/键盘/滚轮 → `Input.dispatch*Event`）
- **新增** Viewer 断线自动重连
- **新增** 连接状态指示器（fade-out 效果）

### `d1d01b1` — fix: multi-viewer support + navigation transition

- **修复** 多 Viewer 互相覆盖 PeerConnection 的问题 → session-based `pcs[sid]`
- **新增** 页面导航时防抖重建流（debounce 1.5s + 重试 3 次）
- **新增** 安全 WebSocket 发送，防止 Viewer 断开时崩溃
- **新增** 导航过渡 loading overlay（毛玻璃 + spinner）

## 迁移说明

V0 的 `cdp_bridge.py` 已完全移除，升级后需重新构建 Docker 镜像：

```bash
docker build -t tabshare:v1 .
docker run -v $PWD:/app --network=host --init --rm --ipc=host tabshare:v1
```
