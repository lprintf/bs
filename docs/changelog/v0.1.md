# v0.1 — CDP 图片传输标签页共享

**日期**: 2026-04-02  
**分支**: `main`  
**提交**: `0254878`  

## 概要

项目初始版本。基于 CDP `Page.startScreencast` 实现标签页实时共享，服务端逐帧截屏为 JPEG 并通过 WebSocket 推送到前端。

## 新增

- TabShare 项目基础结构（FastAPI + Playwright）
- `cdp_bridge.py` — CDP 截屏桥接，`Page.screencastFrame` 回调推送 base64 图片
- `tab_manager.py` — Playwright 浏览器/标签页生命周期管理
- `viewer.html` — 前端 `<img>` 标签播放器
- WebSocket 端点 `/ws/tab/{tab_id}`

## 已知限制

- Python 侧 base64 编解码导致 CPU 开销大
- 帧率和延迟受限于 CDP screencast 机制
- 无音频、无输入控制、不支持多 Viewer
